> ## 📋 Возможности

- **Система уровней** — игроки получают опыт и повышают уровни за различные действия
- **Гибкая настройка опыта** — настройка опыта за убийства мобов, добычу руд, время в игре и другое
- **Интеграция с InternationalQuests** — тип квеста `GAIN_EXPERIENCE` для учёта опыта.
- **Поддержка MySQL/файлов** — гибкое хранение данных игроков (SQLite/MySQL)
- **Система наград** — выдача наград (команды, предметы) при достижении определённых уровней
- **Полная кастомизация** — сообщения, настройки опыта, награды — всё в конфигах

## 🔧 Требования

- Minecraft сервер версии **1.21+**
- **Java 17** или выше (для запуска сервера)
- **JDK 17** или выше (для сборки плагина из исходников)
- **InternationalQuests** (опционально, для награждения за квесты)

## 🚀 Открытие проекта в IntelliJ IDEA

Пошаговая инструкция, которая подойдет даже новичку.

**Шаг 1. Склонируйте репозиторий**

Выполните в терминале:

```bash
git clone https://github.com/MrDevive/InternationalQuests.git
```

**Шаг 2. Откройте проект в IDEA**

- Запустите IntelliJ IDEA
- На экране приветствия нажмите `Open` (или `File` → `Open` в уже открытом проекте)
- Выберите папку, в которую вы склонировали репозиторий, и нажмите `OK`

**Шаг 3. Настройте JDK**

Проект требует Java 17 или новее. Если IDEA попросит выбрать SDK:
- Нажмите `File` → `Project Structure` → `Project`
- В разделе `SDK` выберите установленную версию Java 17+

**Шаг 4. Дождитесь загрузки зависимостей**

Проект использует Maven (файл `pom.xml`). IDEA обычно подхватывает его автоматически и скачивает все нужные библиотеки. Процесс можно увидеть в строке состояния внизу.

Если загрузка не началась автоматически:
- Нажмите на значок Maven справа
- Нажмите кнопку обновления (⟳)

## 🛠️ Сборка плагина

После того как проект открыт и настроен, вы можете собрать его в работающий `.jar` файл.

**Через Maven (рекомендуется):**
1. Откройте панель `Maven` (обычно справа, значок `m`)
2. Раскройте свой проект → `Lifecycle`
3. Дважды кликните на `package`
4. Готовый `.jar` файл вы найдете в папке `target/`

**Через IDEA:**
1. Нажмите `Build` → `Build Artifacts...`
2. Выберите `InternationalLevel:jar` → `Build`

## 📥 Установка на сервер

1. Поместите файл `.jar` из папки `target/` в папку `plugins/` вашего сервера Minecraft
2. Запустите (или перезапустите) сервер — плагин создаст папку `InternationalLevel/` с конфигами
3. Настройте квесты, сообщения и гуи в YAML-файлах (см. раздел Конфигурация)
4. Перезагрузите плагин командой `/quests reload` или перезапустите сервер

## ⚙️ Конфигурация

Плагин создаёт несколько конфигурационных файлов в папке `plugins/InternationalLevel/`:

| Файл | Назначение |
| :--- | :--- |
| `config.yml` | Основные настройки (хранение данных, язык, интеграции) |
| `messages.yml` | Все сообщения игрокам |
| `level_rewards.yml` | Настройка наград за достижение уровней |
| `level_settings.yml` | Настройка уровней |
| `veteran_levels.yml` | Настройка уровней ветерана |
| `experience.yml` | Настройка опыта за различные действия |

**Пример настройки опыта в `experience.yml`:**

```yaml
# Основная конфигурация InternationalLevel

show-exp-messages: true
show-join-message: true

# MySQL настройки
mysql:
  enabled: true
  host: 127.0.1.31
  port: 3306
  database: international_minecraft_auth
  username: root
  password: root

# Настройка опыта за мобов (min и max)
exp:
  mobs:
    AXOLOTL:
      min: 1
      max: 3
    ALLAY:
      min: 1
      max: 3
 # Опыт за блоки
  blocks:
    STONE:
      min: 1
      max: 1
# Настройка опыта за рыбалку
  fishing:
    fish:
      min: 3
      max: 8
    treasure:
      min: 20
      max: 50
    treasure-items:
      - "CHEST"
      - "ENCHANTED_BOOK"
      - "NAME_TAG"
      - "SADDLE"
# Множители опыта по правам
exp-multipliers:
  internationallevel:
    multiplier:
      vip: 2.0
      premium: 3.0
      elite: 4.0
```

**Пример настройки наград в `level-rewards.yml`:**

```yml
# Награды за уровни

rewards:
  2:
    commands:
      - "give %player% stone 64"
      - "eco give %player% 100"
    message: "&aВы получили награду за 2 уровень!"
```

## 🛠️ Команды и права

| Команда | Описание |
| :--- | :--- | :--- |
| `/level` | Показать свой уровень и опыт |
| `/leveladmin addxpp/setexp/setexp [игрок]` | Выдать игроку опыт/уровень/установить опыт |
| `/leveladmin addveteranxp/setveteranlevel/setveteranexp` | Выдать игроку опыт ветерана/уровень/установить опыт |
| `/veteran` | Показать информацию о вашем уровне ветерана |
| `/level reload` | Перезагрузить все конфиги |

## ❓ Часто задаваемые вопросы (FAQ)

**Вопрос:** Можно ли использовать плагин на коммерческом сервере?

**Ответ:** Да. Вы можете использовать плагин на любом сервере, включая коммерческие проекты.

**Вопрос:** Могу ли я изменить код плагина под себя?

**Ответ:** Да, для личного использования на своём сервере. Но вы не имеете права распространять модифицированную версию без письменного разрешения автора.

**Вопрос:** Как добавить опыт за новое действие?

**Ответ:** Добавьте новую секцию в файл `config.yml` или измените существующие значения. Поддерживаются убийства (`mobs`), добыча (`blocks`)и т.д.

**Вопрос:** Плагин не видит InternationalQuests. Что делать?

**Ответ:** [`InternationalQuests`](https://github.com/MrDevive/InternationalQuests) опционален. Без него всё будет работать.

**Вопрос:** Как настроить награду за достижение уровня?

**Ответ:** Отредактируйте файл `level_rewards.yml`. Укажите уровень и список команд, которые нужно выполнить от консоли. В командах можно использовать `%player%` — он заменится на имя игрока.

**Вопрос:** Поддерживается ли MySQL?

**Ответ:** Да, плагин поддерживает два типа хранения данных `mysql` (база данных). Настройка в `config.yml`.

**Вопрос:** Как часто сохраняются данные игроков?

**Ответ:** Данные автоматически сохраняются при выходе игрока и через определённые интервалы (настраивается в `config.yml`).
